Assurance case explorer

An assurance case is a structured argument, supported by evidence, that a system is acceptably safe for a defined use. This website presents an assurance case for an AI-based perception component. The case contains safety claims and cybersecurity claims, and each claim names the clause of the standard it derives from.

Applicability of a performance target under a triggering condition

ISO 21448 defines a triggering condition as a condition of a scenario that initiates hazardous behaviour without a fault. Heavy rain is an example for LiDAR-based perception. This project tests whether an uncertainty threshold of a perception model, selected under one condition, still meets its performance target under a triggering condition. The linked page explains the statistical test without formulas.

School workshop on AI-based perception (in German)

Teaching material

Learners run an object detector, observe where it fails, and derive the engineering response. The material addresses a different question at each level:

  • School: How does a vehicle perceive its surroundings?
  • University: Why does AI-based perception fail?
  • Engineering practice: How is sufficient safety demonstrated?
